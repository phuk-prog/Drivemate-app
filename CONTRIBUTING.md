# Contributions
This is a source-visible proprietary project, not an open-source contribution programme. Please discuss a proposed change with the owner before submitting code. Do not include confidential material, third-party code without compatible rights, credentials or personal data. A pull request is not a copyright assignment. Before accepting substantial outside contributions, obtain a written agreement identifying the contributor, rights granted or assigned, scope, warranties and applicable third-party terms. Any UK copyright assignment must be in writing and signed by the rights holder. Retain records privately. Existing contributor rights are not altered by this notice.
