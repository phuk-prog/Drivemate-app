# Navigation Lab v0 — shared Wells route
Separate QA branch, no production APK changes, no signing secrets. Six subjects: DriveMate original engine/renderer test plus OsmAnd, Organic Maps, CoMaps (related fork), Navit, Navi. The five reference packages are selected from official F-Droid signed index, certificate pinned, bytes verified; unsupported ABI/SDK/install is a blocker. Official F-Droid: https://f-droid.org/en/docs/Running_a_Mirror/ . Actual unmodified reference APKs are launched on an isolated Android emulator using documented route or geo intents. Common real road trace from pinned Wells OSM graph, same start and finish, one-second nominal simulated positions and speed in knots, stationary start, stop and slowdown, arrival. Heading derived from track by apps; exact Android fix uncertainty not identical to DriveMate's injected 5m accuracy. No genuine synthetic traffic feed, no deliberate wrong turn yet. No mock fixes reach a commercial or public traffic service. OsmAnd regional map and locally generated Navit map attempted; CoMaps, Organic Maps and Navi may be blocked by onboarding or unavailable downloaded maps. No automated acceptance of legal terms, account login or restricted data extraction. A successful GPS replay does NOT establish active navigation, and all reference results are explicitly unverified until screenshots/recording reviewed. Emulator screen capture attempts real WebM audio/video, confirms stream presence with ffprobe (audio presence does not imply spoken instructions). DriveMate's own test uses engine states and original rendered frames, not actual live app UI or voice. No claims of comparable scores until actual navigation confirmed. No reference APK or offline map is uploaded as artifact. Evidence contains screenshots of apps, only for review; preserve attributions: © OpenStreetMap contributors https://www.openstreetmap.org/copyright ; Organic Maps Project https://organicmaps.app ; CoMaps https://www.comaps.app ; OsmAnd https://osmand.net ; Navit https://www.navit-project.org ; Navi https://github.com/Supermagnum/Navi . No third-party map or guidance data imported into DriveMate. Google Maps, TomTom, Waze, HERE and other proprietary apps deferred pending permission. Next: provision approved offline maps and deterministic onboarding, confirm actual navigation on each, then align screenshots and recorded speech at verified turns, add legal detour and controlled traffic conditions.
