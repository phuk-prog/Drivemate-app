# Temporary signed APK distribution
Owner-approved official releases are delivered as a single certificate-verified signed APK in GitHub's normal artifact ZIP (no password). Debug and unsigned APKs are internal CI intermediates only. No permanent GitHub Release assets are created.
The APK artifact has a one-hour deletion target based on GitHub's server-created timestamp. The main-only cleanup workflow runs every five minutes and deletes official APK artifacts at age >=3600 seconds plus unapproved Android binaries immediately. GitHub supports a minimum native retention of one day; scheduling delays, disabled schedules, service errors and in-flight downloads mean exact expiry is not guaranteed. Native retention is one-day fallback. Non-installable checksums, manifest and test evidence remain separate. GitHub users with repository read access can download the APK while available; a downloaded copy can be retained or shared and does not stop installing after expiry. Public source can be rebuilt. This is not access control.
Manual cleanup: run the expiry workflow with delete enabled; it also removes legacy matching APK release assets and expires old password-protected APK artifacts. Inspect arbitrary historical archives separately. Do not rerun old workflows. Signing secrets remain required; ZIP password secret is no longer used by current workflows. Keep an owner-controlled last-known-good backup.
