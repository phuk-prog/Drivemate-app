# Password-protected APK distribution
Keep DriveMate public. Official signed APKs are delivered as AES-256 encrypted ZIP archives. The owner sets a strong, unique password (at least 16 characters) in the GitHub Actions secret DRIVEMATE_ZIP_PASSWORD; share it privately with intended recipients. Never reuse the signing password or commit the ZIP password. Use the existing trusted main-only signing workflow and protected drivemate-release environment. No separate private repo or activation system is required. Public validation still builds/tests debug and unsigned binaries without uploading them publicly. GitHub Actions may wrap the encrypted ZIP in an outer unencrypted artifact ZIP: extract the outer file, then open the inner encrypted ZIP with an AES-compatible archive app such as 7-Zip or ZArchiver. Install the verified signed APK as before.
Existing unencrypted artifacts or releases must be audited and removed separately if desired. Previously downloaded copies cannot be recalled. Recipients can redistribute extracted APKs; public source can be rebuilt independently. ZIP encryption protects access to the distributed file, not subsequent use. Map data rights remain unchanged.

## No installable debug or unsigned downloads
Debug and unsigned APKs may exist temporarily on isolated CI runners solely for build, test and signing operations; they are never uploaded. The only distributed Android application is the verified signed APK inside an AES-256 encrypted ZIP. The APK distribution policy check tests both workflow paths and correct/wrong-password behavior on a harmless fixture. Enable this as a required branch check. Disable legacy workflows and prevent reruns of old commits where possible; historical workflow definitions cannot be changed retroactively. Owner can run the manual Remove historical unprotected APK downloads workflow on main with delete checked, or execute bash tools/remove-public-apks.sh --delete from an authenticated CLI. It preserves encrypted artifacts and evidence by name and deletes raw Android release assets; inspect other legacy archives manually. No previously downloaded files can be recalled.
