# DriveMate 2.1 advanced junction intelligence
The engine maps structured manoeuvre and junction codes to presentation categories, selects a speed-aware preview horizon, slices the real route between adjacent instructions, and frames its bounded dimensions. The existing diagram is integrated into the main card only on large screens without competing lane or immediate following-turn content. The arrow and voice remain sourced from the same instruction. No new lanes, arms, signs, traffic signals, exit counts, or lane occupancy are inferred. Some types (T-junction, mini/spiral/multiple roundabouts, lane drop, multi-arm) are supported only when a trusted provider supplies the explicit type; the current routing feeds do not necessarily provide these fields. Full verified topology ingestion is a separate data engineering gate. No proprietary competitor assets or routes imported.
Tests: 50 classification cases plus invalid inputs, adaptive preview horizons, close-turn display, constrained geometry, direction mismatch and right U-turn. These are synthetic unit fixtures, not 50 real road replays. Extend lab with recorded UK routes and compare licensed or permitted competitor screenshots; no rankings before equivalent active navigation evidence. Verify motorway merge/exit, mini/double/spiral roundabout, offset junction, parallel carriageway, stale GPS, reroute, landscape, font scaling and voice on device. 2.0.2 remains frozen. Signed release is only on approved main; no raw APK upload.
