# DriveMate 1.9.0 RC1 offline route preview
Settings > Offline routing downloads the pinned published 24 Nov UK SQLite road graph (2.397 GB compressed) on unmetered Wi-Fi. The manifest hash is pinned to the release asset SHA256; per-part and whole compressed and decompressed checksums are verified before installation. Completed parts are reused on retry; interrupted partial parts restart. No TomTom or server needed for local place-name search or local route previews. No automatic fallback to external routing. Existing online PMTiles partial access and tile cache unchanged. Route engine is bounded; long-distance routes can fail. SHA256 is rechecked on each graph open/search (may be slow on national data); optimise once trust and corruption handling validated. No route turn guidance is fabricated: Start is disabled for local previews. No address/postcode index, lane/speed integration, full regional visual packs, live traffic routing, safe offline reroute or real road validation. Prior hosted provider remains separate. This is a signed/debug candidate, not a stable release.
