# 1.10.0 RC1 original stack
Original DriveMate tiled compiler/Android reader, bounded Java A* with directed connections and turn rules, cached tile sources, place prefix search, way tags, and original Canvas geometry renderer. Pilot is selectable from settings when not navigating; bundled data generated from pinned real Wells source by CI, no TomTom or network necessary. Test compares routes against prior SQLite reference, tests missing coverage and corrupt tiles, and renders a bitmap. Separate signed candidate workflow gates private signing on emulator tests and established owner certificate. No main merge, tag or public release. This is not a production engine or GPU renderer. No native C++/Rust, nationwide streaming compiler, hierarchy, online tile publishing, durable cache/update manager, addresses/postcodes, verified manoeuvre generation, speed/lane display, full GPS reroute integration, live traffic or physical road validation. Existing routing and map rendering remain in place. Map data ODbL 1.0; original implementation, no copied upstream engine code.
