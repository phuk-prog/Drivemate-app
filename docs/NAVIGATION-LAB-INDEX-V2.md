# Run 3: modern signed F-Droid index
F-Droid documents v1 as deliberately signed with deprecated SHA-1 algorithms (https://fdroid.gitlab.io/fdroidserver/fdroidserver.common.html). Run 2 rejected it under Java's current policy. Use official modern entry.jar, verify exact signed entry.json and pinned leaf certificate with normal JDK policy, require fresh timestamp, verify index-v2.json against signed SHA-256 and length, then verify each compatible APK against its signed index hash/size. No security downgrade, no unsigned fallback. Reference APK installation, maps, active guidance and audio still require evidence. This QA-only branch does not change the app or signing workflow.
