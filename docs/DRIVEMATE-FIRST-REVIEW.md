# DriveMate-first experimental candidate
Stacked on v1.7.8 review branch. Configure trusted HTTPS Valhalla /route and Photon endpoints in Settings; neither is deployed by this change. No silent TomTom routing/search fallback when enabled. Uses engine maneuvers, active lane bits where returned, and optional exact-shape trace speed_limit (never routing speed). Old Valhalla versions may not emit lane data; missing data is hidden. Directional/conditional speed accuracy and actual road behavior need validation. Existing TomTom traffic map overlay remains optional; no traffic integration into independent routing ETA yet.
Comparison disabled by default; written permission under the actual TomTom agreement required before enabling. Independent route and separate reference route compared only at confirmed GPS positions, with three-point directed geometry alignment and matched speed sections; close parallel roads still require survey. Findings are RAM-only, deduplicated, shown at journey end, and cleared on the next journey or explicit clear. The share action sends only independently entered observations, never proprietary values or derived location. No automatic OSM edits or data imports. Review actual contract before enabling or retaining any comparison data. OSM corrections require independent survey or compatible official evidence.
Run JVM suite, real service integration tests and passenger-operated device tests before reliance. No deployment, signing, publication, or main merge is implied.
