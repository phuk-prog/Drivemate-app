# RC12: provider-aligned vector journeys and mapped traffic signals
TomTom route journeys request the documented TomTom merged GPU vector style (day/night, optional same-provider flow) rather than paint raster traffic over OSM roads. Independent DriveMate journeys keep their RC11 map and exact shared-geometry option. On provider style failure, return to independent vector fallback with no mixed raster flow and an explicit unverified-alignment diagnostic. No artificial route snapping or widening. Independent bridge road/casing classes are not also painted in normal passes. National static signal locations are extracted from the same verified 25 Nov UK PBF using OSM highway=traffic_signals, sorted and deduplicated in a bounded binary asset, shown from z15 with viewport culling. The icon is a location symbol, not signal state. Signed build generates the full asset alongside Stockport data, tests format and bounds, and retains offline/render gates. Live TomTom credentials and exact photographed journeys are not available for testing in CI; same-provider display reduces source mismatch but does not prove exact alignment. Nationwide Map V2 artifact remains experimental, not deployed.
