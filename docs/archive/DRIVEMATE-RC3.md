# DriveMate RC3 original stack preview
RC3 adds explicit mapped address/postcode lookup in the pilot (coverage not guaranteed), tentative geometry-derived named-way turn candidates, conservative explicit mph and raw one-way lane tag helpers, and an optional Canvas perspective projection. No inferred speed/lane arrows, no verified turn commands, no spoken real-road guidance, no true GPU 3D buildings, no live navigation integration. National routing-only archive lacks raw features; it requires separately sourced same-snapshot intelligence, rendering and search sections. Local pilot only. Signing gate unchanged; production remains unchanged.
