# RC2 map intelligence integration
Independent mode uses Valhalla + Photon HTTPS endpoints, with exact way IDs from edge-walk traces and batched index lookups. Speed limits displayed only when numeric symmetric OSM tag and trace agree and the graph/index source hashes match. Conditional, lane-specific, directional or unknown limits suppressed. No guessed limits. Independent survey notes are app-private across sessions, separately entered by the driver, with manual share/delete; no proprietary comparison values stored. TomTom comparison remains permission-gated and session-only. Existing TomTom traffic overlay remains available, but traffic-aware independent ETA is not implemented. Same stable package and owner certificate verification in branch-scoped signing workflow; never merged or published. Independent services require host deployment, valid graph-source endpoint, full UK index, access controls and real-road testing. On-device offline routing not implemented; cached map display only.
