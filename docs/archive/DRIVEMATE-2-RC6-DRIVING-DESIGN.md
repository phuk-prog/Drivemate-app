# DriveMate 2.0 RC6 — driving renderer redesign
Single pass from RC5 signed candidate. Uses existing MapLibre GPU display and checksum-pinned UK Shortbread tiles, not a screenshot or generated scene. Wider urban camera horizon, more forward lead, pitch up to 54 degrees, projection-based clipping guard. Day/night palette, distinct motorway/trunk/primary styles, rounded strokes, raised footprint blocks (estimated 6m height, not surveyed), real road-reference badges conditional on available source fields, mapped landmarks only. Thick layered cyan/blue route, muted travelled geometry updated only from confident progress. Larger shaded arrow and compass. Current-street text only after repeated unambiguous named rendered line within 12m; omitted if unavailable or ambiguous. Compact dark guidance/ETA panel, road refs highlighted only from provider text, expandable secondary controls with direct End retained. Existing genuine lane/traffic/junction guidance gates unchanged. No invented traffic, lane positions, signs, road names, trees, satellite scenery or geometry. Raster fallback remains 2D and cannot reproduce vector buildings/labels. Some map refs, POIs, junctions and names may not exist in Shortbread z14 or may not be rendered; no hard-coded Stockport details. Real Stockport map range and style contract tests, updated camera tests, existing offline acceptance gate and private signing on exact branch. Device appearance and performance still require a real screenshot/drive test. No published release or main merge.
