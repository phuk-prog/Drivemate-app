# Offline routing feasibility proof
Isolated debug branch; no production navigation code calls the pilot. CI fetches the actual pinned Wells OSM map from DriveMate Map GitHub and verifies the known source SHA-256. Uses the same existing directed graph importer, computes reference journeys with Python, then installs the small graph on an Android API 34 emulator. The test checks that the emulator has no active network, verifies the SQLite digest, computes routes on-device, checks reference distance and cost and tests turn rules. Separate CI probe verifies online range access to the real UK display PMTiles. This does not test Android downloading a multi-GB national routing pack directly, does not add route UI or native Valhalla, and does not certify navigation. The source XML is downloaded by the CI runner, the generated graph is transferred in test APK. Real phone memory, storage, long routes, safe snapping, restricted turns, offline search and lane guidance remain to be validated. Map source © OpenStreetMap contributors, ODbL 1.0.
